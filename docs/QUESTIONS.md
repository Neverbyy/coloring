## Что озвучить как план (не вопрос, а предложение)

- Стек: Nuxt 4 + TypeScript, Postgres (Supabase или Neon), деплой на Vercel.
- Рендер: canvas поверх SVG, каждый сегмент — отдельная маска/Path2D; рисование обрезается по сегменту, на котором началось касание.
- Архитектура: общий «слой платформы» (вход, сессия, галерея, аналитика, админка) + игра «раскраска» отдельным модулем (Nuxt Layers или `games/coloring`).
- История: журнал операций (штрих/заливка/очистка) + периодические снимки состояния; undo/redo не тормозит и работает после перезагрузки.
- Аналитика: события «открыл», «начал» (первый штрих), «завершил» (100%); в админке — уникальные пользователи по артам.
- Админка: в том же приложении на `/admin`, отдельный вход, проверка роли на сервере для всех `/api/admin/*`.
- Сохранение/шеринг: PNG без интерфейса через Web Share API («Сохранить изображение» в системном окне), где недоступно — скачивание файла. Прямое сохранение в галерею без подтверждения в браузере невозможно — это ограничение платформы.
- «Нативность»: без скролла, выделения, зума, pull-to-refresh и меню по долгому тапу.
- Безопасность SVG: санитизация (скрипты, внешние ссылки, обработчики событий), лимит размера, проверка на сервере.
